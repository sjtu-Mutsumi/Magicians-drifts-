# v1.2 构筑与赛事

权威配置：[economy.json](economy.json)、[damage.json](damage.json)、[probabilities.json](probabilities.json)。客户端与模拟器共用 tools/sim_v12/tournament.py。

- 基础研习：1—3轮2点、4—7轮3点、8轮起4点；结余最多继承2点；连胜败每满3场的奖励按 economy.json。
- 免费购买：1—2轮首张普通免费；3—4轮首张普通或稀有免费；每轮一次，两面共用。
- 每轮最多刷新一次，费用1点；买过的位置保持空缺。
- 删牌：1—3轮不可；4—6轮最多一次、费用1；7轮起最多两次、费用依次0和1。最低8张，保护能力牌、传奇和主系最低数量；删牌弹窗可退出。
- 初始8张：攻击强化×2、防御强化×2、护盾、检索附魔、短促、重洗；初始牌不进入市场。183张定义、677份流通库存。
- 四人同步赛事：每轮先公布配对，构筑后战斗，按配置扣除赛事生命，淘汰者可观战，最终产生排名。幽灵配对与回池逻辑以权威内核为准。

当前客户端为 v1.2，旧版规则与研究报告已移出活动项目。
