# Magicians! 世界观与创作入口

- 版本：lore v0.2，2026-10-24
- 当前概念：**魔法集会与魔法师大赛**。魔法贴近生活，比赛认真，人与人的关系温暖而有摩擦。
- 本目录负责背景、人物、美术方向和表达，不定义玩法，也不代表客户端已实现。

## 一句话背景

**每年秋天，各地魔法师带着新咒语和家乡特产来到魔法集会。白天交流手艺，比赛间隙整理咒语书，在魔法师大赛上用这一年的新本领击败老朋友。**

魔法师平日修桥、行医、送信、烧窑和经营小店。大集让这些互不相同的生活相遇；大赛让他们证明自己的手艺究竟有多好。

## 规则来源与关键边界

- 卡牌唯一数据：[cards.json](../../releases/v1.0/cards.json)，253张。当前卡名仅是现有名称，不等于已完成新世界观改名。
- 构筑与赛事唯一规则：[构筑v1.0](../../releases/deckbuilding-v1.0/README.md)。四人各100赛事生命；可发生最终同时淘汰、并列冠军。
- 战斗与时序：[同步结算](../combat/resolution-order.md)、[伤害](../combat/damage-model.md)、[数值规范](../combat/numeric-standards.md)。战斗生命与赛事生命独立。
- 收集三张同系附魔确定专精；打出专精牌才激活对应专精机制。收藏牌、战斗附魔层和机制资源不能混为一谈。
- 传奇按现行候选、购买和保底规则获取，不沿用旧版“所有传奇统一三选一”的说法。
- 当前世界设定不扩充为新玩法，不调整库存、出率、研习经济或公开信息边界。

## 创作原则

1. 先能听懂，再有韵味。卡牌、牌组、专精、费用、生命不必另造专名。
2. 魔法首先是一门生活手艺；人物有工作、朋友、烦恼和自己的研究。
3. 比赛认真，失败有失落，但安全结界让人能打完继续一起吃饭。
4. 地域提供不同生活方式，不把五系写成五种单一性格或善恶阵营。
5. 卡名提供画面，效果文本提供精确规则，风味文本提供人物温度。
6. 先用少量样张确定风格，再量产；本版仅提出美术方向，尚未生成或锁定资产。

## 本次修订

旧版五份世界观文档及产品概念已原样归档。停用“环宴、环主、环印、战息、定环”等自造术语，不再以大陆级圆环为世界中心。保留老朋友重聚、魔法是手艺、五系生活文化、安全竞技的创作基础。旧文档中的过时数值和规则不迁入新版。
