# 美术方向：看得见生活的魔法集会

版本：lore v0.2，2026-10-24。本文是候选制作方向，不代表已确认最终画风或已生成素材。背景见[世界设定](world.md)，人物见[人物设定](characters.md)。

## 1. 第一眼要读懂什么

**一座正在举办魔法集会的小镇，一群有自己手艺的魔法师，一场让老朋友认真起来的大赛。**

主视觉应同时给出生活、魔法和比赛的线索：前景是翻开的咒语书与工具；中景是结界中对战的两人；周围是看台、摊位、桥梁和观众。不要只用一片奇幻森林或空中的巨大法阵承担背景介绍。

建议基础：手绘故事书质感、风格化人物、清楚的轮廓和大色块，辅以纸张、陶器、织物、玻璃、木材和哑光黄铜。保留温暖与手作感，减少旧版繁密的手抄本装饰和统一圆环符号。最终线条、笔触、比例与细节密度通过样张选择，不在此阶段强制锁死。

## 2. 生活与竞技的视觉关系

生活画面提供出处，比赛画面展示同一手艺如何被推到极致。不是每张卡都画做饭，也不是每个角色都拿法杖。

| 系 | 日常画面 | 竞技画面 | 形状、材质 |
|---|---|---|---|
| 火 | 窑火、夹钳、陶制蓄热罐 | 火星聚拢，集中释放 | 楔形、开裂陶壳、炭屑、热金属 |
| 水 | 量杯、渡船、净水槽 | 回流、蓄水、清楚的水位变化 | 曲线、透明玻璃、湿石、薄水膜 |
| 土 | 桥拱、楔块、砌石 | 层叠盾面、受力裂纹、碎石反应 | 厚块、拱形、层理、陶与石 |
| 风 | 信件、织带、风标、风笛 | 定向气流、连续而分段的尾迹 | 斜线、窄弧、布带、羽毛 |
| 毒 | 药草架、菌种罐、滴管 | 渗透、分枝侵蚀、定量反应 | 分枝、点簇、液滴、磨砂玻璃与菌丝 |
| 通用 | 书签、装订工具、粉笔、训练器具 | 阅读、检索、调整施法结构 | 书页、折角、夹扣、木与纸 |

形状与符号必须辅助色彩识别。水与风不能只靠深浅蓝区别；火和毒的持续效果也不能复用同样的发光小球。毒系美丽、有生命力，可以微妙不安，但不默认邪恶。

## 4. 场景与人物规范

- 集会：帐篷、临时木桌、河岸建筑、工具、食品与行李；魔法有具体用途，别让每件物品都无缘无故漂浮。
- 竞技场：由日常广场布置而成，有安全边界、观众席和施法位置；材质与小镇连续，不像另一座神殿。
- 研习区：翻开的书、材料托盘、归还箱、讲解员；不能把有限共享库存画成无限复制的书页喷泉。
- 角色：职业先于元素装饰，通过衣服磨损、携带工具和常用动作区分。所有人都应有完整生活身份。
- 光照：集会可用秋日暖光和夜间灯光；卡牌同批次使用一致的光照逻辑。魔法照亮手、脸和器具，避免全身被元素光淹没。
- 幽灵：用纸页纹理、半透明轮廓和记录感表现复制对手，与普通人物清楚区分；不用亡魂或墓地符号。

## 5. 卡牌与战斗的可读性

卡牌插画只承担一个主体或一个明确动作。核心物件不能靠放大才能辨认；背景交代出处，但不与主体争夺注意力。稀有度提高表现的独特性和研究规模，不靠更多边框、珠宝与光污染。

框架、费用、数值、名称、效果文本由界面排版合成，生成插画时不画文字、伪文字、水印、标志或假卡框。安全区、裁切与宽高比要等实际卡框和素材类型明确后确定；不能默认全卡插画都用同一个构图。

战斗中至少区分：构筑确定专精、打出专精牌、普通附魔层、专精资源、主弹与副弹、护盾与生命损失。风痕是路线机制，未激活时不能作为所有风系攻击的默认标记。治疗与攻击尾迹的方向、节奏或形状应有明显差别。

现有含“弹仓、弹头、火药”等词的卡牌可先用陶罐、药囊、铜制导流器表现。是否改名在逐卡文案阶段决定，不能为旧卡名直接引入现代枪械。

## 6. 素材生产顺序

| 阶段 | 建议产物 | 要解决的问题 |
|---|---|---|
| 风格探索 | 同一个桥头集会场景的少量风格变体 | 线条、笔触、人物比例、热闹程度是否合适 |
| 风格验证 | 同一风格的生活场景、人物、法术卡各一张 | 场景好看之后能否稳定用于小卡面 |
| 五系验证 | 五系各一张代表卡 | 去掉文字仍能否分辨元素、动作与主体 |
| 规范固化 | 选定参考、配色、角色三视要点、构图与裁切模板 | 后续生成能否保持一致 |
| 分批制作 | 卡牌插画、人物、场景、界面底材、特效概念分批 | 逐批审核，不用一张图兼任所有用途 |

## 7. 每项素材的交付记录

后续素材建议放在 assets/art/lore-v0.2/ 下，按 concept、characters、cards、scenes 分目录；这是规划，本次不创建空资产或占位图片。

每项记录：素材ID、用途、关联卡牌稳定ID、元素、主体动作、目标尺寸、裁切安全区、透明背景需求、采用的风格参考、生成提示、版本和审核状态。生产卡牌时使用稳定ID命名文件，避免改卡名导致素材失联。

首张概念图构图草案：河边集会的广场，两位穿工作服的魔法师在结界里较量，一侧打开咒语书，一侧以工具引导附魔飞弹。前景有来不及收起的茶杯和笔记，后方是摊棚、石桥与认真围观的朋友。图中不包含任何文字。它应首先让人看懂“魔法师正在集会比赛”。

## 8. 审核问题

1. 第一眼能看出魔法、生活与比赛吗？
2. 人物在做具体的事，还是只有站姿和发光？
3. 缩到目标尺寸，主体和元素仍清楚吗？
4. 五系是否同时依靠形状、材质与颜色区分？
5. 图像有没有暗示卡牌实际不存在的效果或资源？
6. 同批角色、材质与绘画语言是否一致？
7. 文字和界面是否能由游戏清楚排版，而非嵌进生成图？
