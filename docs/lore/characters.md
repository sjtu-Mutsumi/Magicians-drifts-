# 人物设定：来赶集的老朋友

版本：lore v0.2，2026-10-24。人物姓名、外形与关系是可调整创作草案；核心方向见[入口](README.md)，背景见[世界设定](world.md)。保留部分旧版姓名以便追踪，旧称号与组织身份停用。

## 1. 人物的共同基础

他们曾在公共大工坊参加同一届进修班，后来各自回到家乡工作。有人留下任教，有人经营小店，有人一直在路上。他们并不代表全大陆最强的五个人，也不是五系的唯一权威。

每年集会，他们在桥头的同一张长桌碰面。先聊工作，再交换新咒语，最后总有人提起去年的比赛。五位常驻人物是群像，不是五人局设定，也不是本版新增的五个带独立技能的可选英雄。

## 2. 主持人：柯温

**身份**：公共大工坊的老教师，兼大赛主持与安全检查负责人。旧衣整洁，墨蓝围裙，阅读眼镜挂在胸前，随身带粉笔、钥匙和茶杯；不佩戴统治者徽章。

他想让新手敢于尝试，也想让老朋友们别把安全检查当作寒暄。温和、说话短，遇到含混规则会要求重说一遍。烦恼是大家都相信他能修好所有东西，于是总忘了替他分担。

- 对外目标：让集会安全、有秩序，让研究值得被认真讨论。
- 私人愿望：明年能坐在观众席上，把一杯茶从热喝到温。
- 关系：教过五位老朋友；认可他们已经独立成才，仍忍不住纠正装订习惯。
- 台词：“配对已经公布。可以改牌组，别改公告板。”“输了可以不服，规则得先说清楚。”
- 美术重点：磨损袖口、分格工具袋、茶杯盖；通过职业和动作体现权威，不靠华丽法杖。

## 3. 火系：伊格娜

**身份**：赤炉丘的窑炉修理师，兼烟火制作师。愿意在开集前帮所有人检查炉子，但对别人乱调火候十分计较。

- 生活中的本领：让窑炉均匀受热，把余热留给下一批器物。
- 比赛中的研究：怎样积蓄火力，在合适的时机集中释放；不默认每次攻击都慢。
- 外形草案：结实身形、挽起的袖子、朱红短外套、炭色围裙、厚手套；工具是陶制蓄热罐和夹钳。
- 性格矛盾：嘴上直来直去，实际很怕让委托人失望；输了会先怪工具，再偷偷练习。
- 与朋友：常请奥仑帮忙改炉基；和塞拉争论是准备充分重要，还是出手够快重要。
- 台词：“别浪费这点余火，还能烤一盘。”“这一招我改了一年，你可得认真接。”
- 插画动作：夹起烧红的陶片，光照亮脸与手；战斗版让蓄热罐的火星汇入飞弹。

## 4. 水系：玛琳

**身份**：芦湾疗养所的医师，也替附近渡口维护净水设施。医术需要观察与照料，绝非一挥手就解决一切。

- 生活中的本领：控制流量、循环净水、精细处理药液和敷料。
- 比赛中的研究：把恢复与回流组织成持续的攻防节奏。
- 外形草案：深青工作长衣、短披肩、防水书袋；玻璃量杯、导流软管与珍珠色陶碗。
- 性格矛盾：善于照顾别人，却不习惯承认自己也想赢；会把挑衅说得像关心。
- 与朋友：薇尔常寄来新药材，两人为配方讨论到深夜；她记得每个人去年的借口。
- 台词：“先喝水，再解释你为什么输了。”“你这一年进步不少。我也是。”
- 插画动作：把溢出的水珠导回容器；战斗版的回流水线与攻击水流有清晰方向区别。

## 5. 土系：奥仑

**身份**：石阶岭的桥梁修缮师，经营一间小型石工作坊。他关心的是桥修好以后，十年后还能不能用。

- 生活中的本领：承重、砌筑、分配冲击，利用旧材料加固结构。
- 比赛中的研究：建立防护，在承受压力后作出反应；具体反伤与破盾条件只按卡牌执行。
- 外形草案：宽肩、赭石工作服、补过的护膝、石灰白袖口；木尺、石锤、楔块与陶印。
- 性格矛盾：可靠但固执，常把“还可以再改好一点”当作拖延交稿的理由。
- 与朋友：每年提前到镇上检查看台；经常帮伊格娜收拾试验残局，也欠她一次窑炉改造。
- 台词：“坐吧，这张凳子是我修的。”“别急，撑得住。下一发再说。”
- 插画动作：用楔块撑住裂开的石拱；战斗版的护盾是叠砌结构，不是一团黄光。

## 6. 风系：塞拉

**身份**：长风原邮差，偶尔替乐队修风笛。她认识沿途旅店、天气和许多叫不上全名的人。

- 生活中的本领：控制气流、校准落点、维持连续节拍。
- 比赛中的研究：缩短无效等待，让连续攻击更准确。
- 外形草案：修长身形、天青短斗篷、耐磨靴、斜挎邮袋；织带、哨笛和有刻度的风标。
- 性格矛盾：喜欢表现得轻松，其实很认真记录每次失误；害怕被当作只会跑腿的人。
- 与朋友：替大家捎信，也最先知道谁在偷偷练新招；会逗奥仑说话，但从不随意泄露私人信件。
- 台词：“这次不是顺路，我专门来赢你的。”“风没变，是你还在用去年的节拍。”
- 插画动作：让几封信沿定向气流依次落进格子；战斗版以分段尾迹表现节奏。

## 7. 毒系：薇尔

**身份**：菌雨林的药草师，经营菌菇苗圃，研究发酵与材料分解。她的小罐子标签写得最清楚，绝不让食物与试剂混放。

- 生活中的本领：培养、剂量控制、维持活性、把废料转为可用材料。
- 比赛中的研究：让细小影响积累，掌握维持和引爆的时机；并非所有路线都能引爆。
- 外形草案：梅紫罩衣、橄榄色围裙、密封玻璃罐、陶滴管、种植托盘；酸黄仅作少量点缀。
- 性格矛盾：好奇心旺盛，讲研究时容易忘记别人听不懂；被误解时会先冷笑，再耐心解释。
- 与朋友：与玛琳互相审配方；送给柯温的茶永远有明确标签；和伊格娜共同研究耐热菌陶。
- 台词：“这是试剂。茶在另一边，标签上写着呢。”“别催，变化已经开始了。”
- 插画动作：向枯叶堆滴入试剂，露出下面的新芽；战斗版以侵蚀纹路和受控孢子表现，不用骷髅绿烟。

## 8. 关系与冲突

每个人都要有元素之外的喜好、缺点和成长，不把火系等同暴躁、水系等同温柔、土系等同木讷。

| 关系 | 常见争论 | 能体现友谊的行动 |
|---|---|---|
| 伊格娜与奥仑 | 炉子究竟先升温还是先加固 | 互相保留一套备用工具 |
| 玛琳与薇尔 | 配方应以经验还是新试验为准 | 对外替对方澄清误解，对内照样挑错 |
| 塞拉与伊格娜 | 速度与蓄势谁更有价值 | 赛前调侃，赛后认真交换笔记 |
| 柯温与众人 | 老师该不该继续操心 | 众人瞒着他排好收摊值班表 |

## 9. 玩家、常驻配角与播报

玩家可被写为归来的同行或新到访的参赛者；两者不同时强行成立。教程需要共同前提时，只说“欢迎来参加魔法师大赛”。玩家的角色设定不限制其主修元素或构筑路线。

可用配角包括：负责施法用页出入库的图书管理员、会用保温咒的面包师、负责看台的学徒、为各地选手保管行李的旅店主人。先按职能创作，不为了填地图批量添加专名。

旧版圆环精灵不作为新版默认角色。本版暂由主持人、学徒和公告板完成引导；是否需要新的吉祥物留待美术讨论。

播报先准确说明事实，再补一句性格化反应。例如“塞拉已确定风系专精。”“她可不只是来送信的。”不得在专精确认时宣称专精机制已经激活，不得播报私有牌组内容。
