# 卡牌命名指南

- 版本：lore v0.1
- 上游：[README.md](README.md)、[world.md](world.md)
- 用途：新卡命名、旧卡审查、英文名、卡面文案、本地化
- 原则：**名字是画面，不是说明书；先统一语域，再追求好听。**

---

## 1. 目标与边界

### 1.1 目标

- 玩家看到卡名，能立刻在脑中浮现一个画面。
- 玩家看到同一系的卡，能感觉它们来自同一个世界。
- 玩家看到稀有度，能大致判断这张牌的分量。
- 玩家看到传奇，能记住它、讨论它、用它给牌组命名。
- 美术看到卡名，能直接画出构图，不需要再问“这是什么意思”。

### 1.2 边界

- 本文不修改规则与数值；卡名与效果以 `../cards/*` 为准。
- **现有卡名不回改**；新卡遵循本指南。若确需改名，走归档流程，并同步卡表、牌组、模拟器与本地化。
- 中文是正典；英文名用于美术提示词、本地化草案与对外宣传，不是最终法律文本。
- 本文的“词库”是建议，不是封闭列表；但新增词必须符合该系的材质、动作与气质。

## 2. 命名的四个层次

| 层次 | 例子 | 规则 |
|---|---|---|
| **世界 / 地名** | 环洲、环心原、环庭、赤炉丘、澜泽、磐岭、长风原、雾孢泽 | 2–4 字；地理特征 + 意象；不要用现实地名 |
| **组织 / 称号** | 守环人、环主、环灵、刻环者、环庭学院、环工、环纹师 | 2–4 字；功能 + 身份；不要用“公会”“联盟”等通用奇幻词 |
| **卡牌** | 火星、慢燃、潮汐回响、不周山、禁忌知识 | 2–5 字；画面 + 语域；见下文 |
| **UI / 机制** | 行动值、费用、牌组、附魔层、专精、传奇 | 以可读性为先；世界观说法只用于风味文本 |

**重要**：卡面效果文本一律使用规则术语（行动值、费用、抽牌、护盾、附魔层），不要用“环刻”“咏息”“浮页”等 lore 词。Lore 词用于风味文本、教程旁白、加载界面、成就名、战斗播报。

## 3. 七条硬规则

### 规则 1：字数控制在 2–4 字，传奇最多 5 字

- 普通牌以 1–2 字为主，允许 3–4 字的功能复合名（火种翻找、烈焰冲刺）。
- 稀有 / 史诗以 2–4 字为主。
- 传奇 2–5 字；超过 5 字会压到卡框、费用与元素符文。
- 1 字卡名只在极端情况下使用（如“盾”“愈”），目前卡库不用。

**检查**：把名字放进卡框顶部横幅，是否还剩至少 20% 留白？

### 规则 2：名字是画面，不是说明书

- 好名字：慢燃、余烬刻度、潮汐回廊、风痕刻印、固毒。
- 坏名字：火焰伤害提升、风系速度强化、毒层增加术。
- 先写效果，再问：“如果这张牌是一幅画，画里是什么？”画里的事物，才是名字。

**检查**：这个名字能不能直接交给美术，说“画这个”？

### 规则 3：元素靠词根与意象，不靠前缀堆叠

- 不要每张火系牌都叫“火X”，每张水系牌都叫“水X”。
- 用该系的材料、动作、现象、工具构成名字：火可以用炉、烬、烟、炭；水可以用潮、汐、泉、渊；土可以用岩、壁、垒、脉；风可以用岚、痕、隙、羽；毒可以用蚀、腐、孢、酿。
- 元素身份应该从“词的味道”里出来，而不是从“元素前缀”里出来。

**检查**：去掉元素前缀，这个名字还能看出是哪一系吗？

### 规则 4：稀有度决定语域

| 稀有度 | 语域 | 感觉 | 现有例子 |
|---|---|---|---|
| **普通** | 日常、材料、动作 | 学徒在课堂上会说的词 | 火星、火苗、水滴、石肤、微风、毒刺、火种翻找 |
| **稀有** | 手艺、工具、技法 | 工匠会用的词 | 压实火药、导火索、余烬刻度、潮涌、岩甲、风步、毒瓶、速腐、延毒 |
| **史诗** | 仪式、诗意、成型 | 大魔法师的招牌 | 慢燃、灰烬重生、焰心屏障、奔流、圣盾、破军、永恒壁垒、命运检索、万蚀、蚀界、风痕回廊 |
| **传奇** | 专名、流派、法相、自然现象 | 会被写进环藏的名字 | 燃烧血统、不周山、天岚、万毒之源、禁忌知识、时光倒流、燎原、山崩 |

**检查**：把名字按稀有度排在一起，普通像普通，传奇像传奇吗？

### 规则 5：不撞名、不近义混淆；同根必须同族

- 全卡库唯一；不要出现“火焰弹 / 火球 / 火弹”三张效果不同的牌。
- 同一词根可以形成家族，但家族成员的效果必须相关：
  - 余烬 / 灰烬 / 火种：火焰资源与循环。
  - 潮 / 汐 / 泉 / 回响：水系治疗与潮汐资源。
  - 岩 / 盾 / 壁 / 垒：土系护盾与碎盾。
  - 风痕 / 裂空 / 穿云：风系叠痕、爆发、穿透。
  - 蚀 / 腐 / 毒：毒系层数与衰败。
- 如果两张牌同根但效果无关，改掉其中一张的名字。

**检查**：在卡库搜索这个词根，是否已有不同效果的牌？

### 规则 6：不破坏世界观

- **不要**现代 / 军事 / 科幻词：枪、炮、子弹、激光、核、蒸汽、机械、电子、网络、手机、电脑。
- **不要**把毒系写成邪恶：邪、恶、魔、鬼、尸、死、地狱、诅咒、瘟疫医生、骷髅。
- **不要**现实宗教 / 政治 / 疾病隐喻：十字、天使、圣战、国王、议会（作为卡名）、新冠等。
- **慎用**“圣”：圣盾、愈合之光是现有例外；新卡优先用“守护”“壁垒”“辉光”，避免十字与天使。
- **慎用**“神 / 战神”：战神徽记是现有例外；新卡优先用“战意”“徽记”“誓约”，避免具体神祇。
- 火系的“弹仓、弹头、火药”是黄铜 / 陶制的咒式容器，不是火器；新卡不要延伸出枪管、扳机、子弹。

**检查**：这个名字放进中世纪手抄本的世界，会不会让人想到现代军队、恐怖片或现实宗教？

### 规则 7：可读、可记、可说

- 读出声；不要绕口、不要生僻字堆叠。
- 玩家应该能在语音里说清楚：“我打一张潮汐回廊”，而不是“我打一张那个……什么回廊”。
- 避免同音歧义：湿/蚀、焰/艳、泉/全、壁/闭。
- 避免过度抽象：虚空、永恒、终焉、寂灭（除非是传奇，且有必要）。

**检查**：让一个没看过卡表的人听一遍，能不能复述出来？

## 4. 稀有度语域表

| 稀有度 | 字数 | 构词倾向 | 动词 / 名词 | 避免 |
|---|---|---|---|---|
| 普通 | 1–4（多为 1–2） | 材料 + 动作；日常物件 | 火星、火苗、水滴、石肤、微风、毒刺、火种翻找、烈焰冲刺 | 抽象、宏大、规则文本 |
| 稀有 | 2–4 | 工具 + 用途；技法 | 压实火药、导火索、余烬刻度、潮涌、岩甲、风步、毒瓶、速腐、延毒、握盾 | 过于诗意、过长 |
| 史诗 | 2–4 | 仪式 + 意象；成型 | 慢燃、灰烬重生、焰心屏障、奔流、圣盾、破军、永恒壁垒、命运检索、万蚀、蚀界、风痕回廊 | 纯功能名、纯数值名 |
| 传奇 | 2–5 | 专名；流派；法相；自然现象 | 燃烧血统、潮汐回响、不周山、天岚、万毒之源、禁忌知识、时光倒流、燎原、山崩 | 通用、无画面、像普通牌 |

说明：

- 字数不是硬性审美标准，**语域**才是。普通牌可以 4 字（火种翻找），但它必须听起来像“一个动作”；传奇可以 2 字（天岚、燎原），但它必须听起来像“一个专名”。
- 史诗不是“更长更中二”，而是“更完整、更有仪式感”。
- 传奇不是“更大声”，而是“更少、更准、更像唯一”。

## 5. 构词公式

### 5.1 十个常用公式

| 公式 | 结构 | 例子 | 适用 |
|---|---|---|---|
| **意象 + 载体** | 元素意象 + 物件 | 火墙、岩甲、水膜、毒瓶、风刃 | 普通 / 稀有 |
| **动作 + 对象** | 动词 + 名词 | 寻岩、寻风、寻毒、破甲、裂伤、火种翻找 | 普通 / 稀有 |
| **状态 + 核心** | 状态词 + 核心名词 | 慢燃、静水、不灭烈焰、永恒壁垒、不坏壁垒 | 稀有 / 史诗 |
| **资源 + 计量** | 资源 + 刻度 / 账本 / 回廊 | 余烬刻度、灰烬账本、潮汐回廊、风痕刻印 | 稀有 / 史诗 |
| **工具 + 用途** | 工具 + 功能 | 导火索、高压弹仓、爆裂弹头、毒囊、毒瓶 | 稀有 |
| **动作隐喻** | 动词 / 动词 + 名词 | 反震、回响、循环、回火、回潮、固毒、延毒 | 稀有 / 史诗 |
| **专名 / 流派** | 专有概念 | 燃烧血统、潮汐回响、不周山、天岚、万毒之源 | 传奇 |
| **自然现象** | 天象 / 地质事件 | 燎原、山崩、飓风、瘟潮、深渊潮 | 5 层传奇 |
| **权威名词 / 法相** | 冠 / 心 / 山 / 岚 / 源 | 炽焰王冠、潮汐之心、不周山、天岚、万毒之源 | 专精 |
| **通用功能** | 平实功能名 | 攻击强化、防御强化、护盾、检索附魔、重洗 | 基础牌 / 通用牌 |

### 5.2 公式组合示例

- **火**：余烬（资源）+ 刻度（计量）= 余烬刻度；灰烬（意象）+ 账本（载体）= 灰烬账本；慢（状态）+ 燃（动作）= 慢燃。
- **水**：潮汐（资源）+ 回廊（载体）= 潮汐回廊；血（意象）+ 刃（载体）= 血刃；濒死（状态）+ 回响（动作）= 濒死回响。
- **土**：碎岩（动作）+ 印记（载体）= 碎岩印记；回（动作）+ 震（动作）= 回震；不坏（状态）+ 壁垒（核心）= 不坏壁垒。
- **风**：风痕（资源）+ 刻印（计量）= 风痕刻印；穿云（动作）+ 箭（载体）= 穿云箭；裂空（动作）+ 穿云（动作）= 裂空穿云。
- **毒**：蚀（动作）+ 骨（对象）= 蚀骨；固（状态）+ 毒（资源）= 固毒；万毒（程度）+ 爆（动作）= 万毒爆。

### 5.3 反例

| 反例 | 问题 | 改法 |
|---|---|---|
| 火焰球 | 太通用，像所有奇幻游戏的初始法术 | 火星 / 火花 / 猛火弹 |
| 超级大火球 | 没有画面，只有程度 | 燎原 / 不灭烈焰 |
| 火系终极奥义 | 像技能树，不像卡牌 | 燃烧血统 / 炽焰王冠 |
| 烈焰焚烧一切 | 太长，像说明书 | 燎原 / 焚心 |
| 风之速度提升 | 规则文本，不是名字 | 风步 / 疾行 / 顺风 |
| 岩盾防御强化 | 冗余，两个功能词堆叠 | 岩甲 / 坚壁 / 磐岩壁 |
| 毒之邪恶诅咒 | 毒系被写成邪恶，破坏世界观 | 蚀命 / 腐息 / 瘟潮 |
| 火焰枪 | 现代火器，破坏中世纪基调 | 火舌 / 猛火弹 / 高压弹仓 |
| 治愈之刃 | 名字承诺治疗，实际是伤害牌 | 血刃 / 蚀创 |
| 环之打击 | 滥用世界核心词“环”，稀释品牌 | 碎岩印记 / 回震岩甲 |
| 冰霜新星 | 水系没有冰；越界 | 潮涌 / 深渊 / 水幕 |
| 雷神之怒 | 雷系暂缓；宗教感过强 | 风暴 / 天岚 / 飓风 |

## 6. 五系词库

> 用法：核心词可自由组合；辅助词适合特定机制；慎用词需要理由；禁用词不要碰。

### 6.1 火

| 类别 | 词 |
|---|---|
| **核心** | 火、焰、烬、燃、灼、燎、炉、炭、烟、赤、暖 |
| **辅助** | 爆、烈、猛、焚、灰、星、舌、苗、花、墙、冲刺、弹、仓、索、引 |
| **慎用** | 血（水系血潮路线）、热（太平）、光（通用神圣感）、圣（现实宗教感） |
| **禁用** | 冰、雷、电、枪、炮、核、地狱、恶魔、邪 |

火系气质：热、干、快、亮；材质是热金属、炭、黄铜、玻璃；动作是压、烧、淬、敲。

### 6.2 水

| 类别 | 词 |
|---|---|
| **核心** | 水、潮、汐、泉、流、澜、涌、浪、润、露、渊、回响 |
| **辅助** | 血（仅血潮路线）、愈、静、深、清、涟、幕、膜、滴、刃、偿、怒、濒死 |
| **慎用** | 海（太大）、泪（太煽情）、圣（现实宗教感）、冰（暂缓，别越界） |
| **禁用** | 枪、炮、酸、毒（毒系领域）、邪 |

水系气质：润、慢、深、回；材质是玻璃、珍珠、湿石、茶；动作是流、回、涌、沉。

### 6.3 土

| 类别 | 词 |
|---|---|
| **核心** | 岩、石、土、壁、垒、山、磐、盾、脉、根、矿、铸 |
| **辅助** | 厚、重、稳、固、裂、碎、震、甲、肤、拳、握、岳、岩核 |
| **慎用** | 铁 / 钢（太工业）、沙（沙漠感，不是磐岭）、泥（太弱）、不周（专精专用） |
| **禁用** | 枪、炮、机械、蒸汽、邪 |

土系气质：稳、重、慢、久；材质是花岗岩、苔藓、陶、石灰；动作是叠、压、裂、撑。

### 6.4 风

| 类别 | 词 |
|---|---|
| **核心** | 风、岚、云、羽、翼、痕、隙、疾、迅、翔、旋、裂空 |
| **辅助** | 追、穿、破、轻、高、远、牙、步、眼、卷、幕、刃、顺、驰 |
| **慎用** | 雷 / 电（暂缓）、暴 / 台风（太灾难）、刀 / 剑（太武术，少量） |
| **禁用** | 枪、炮、飞机、引擎、邪 |

风系气质：轻、快、远、利；材质是丝绸、羽毛、银、云；动作是掠、切、追、回。

### 6.5 毒

| 类别 | 词 |
|---|---|
| **核心** | 毒、蚀、腐、疫、瘴、孢、菌、酿、酵、苦、涩、源 |
| **辅助** | 刺、针、瓶、囊、触、刻、枯、衰、牙、骨、甲、雾、息 |
| **慎用** | 瘟（只用于传奇 / 自然现象）、疫（自然枯萎，不是生化武器）、血（水系）、暗 / 影（容易邪恶） |
| **禁用** | 邪、恶、魔、鬼、尸、死、地狱、诅咒、瘟疫医生、骷髅 |

毒系气质：湿、慢、繁茂、微苦；材质是菌菇、玻璃罐、苔藓、陶、果酱；动作是渗、蚀、酿、腐、生。

### 6.6 通用 / 中立

| 类别 | 词 |
|---|---|
| **核心** | 攻、防、盾、愈、检索、翻找、循环、命运、战术、战意、守护、壁垒、通晓、灵感 |
| **辅助** | 强、弱、破、裂、蓄、速、整、理、寻、物、备、势 |
| **慎用** | 元素词（火 / 水 / 土 / 风 / 毒）——通用牌不应抢元素身份 |
| **禁用** | 环 / 宴 / 庭 / 守 / 主 / 灵 作为随手卡名；现代 / 军事 / 科幻词 |

通用牌气质：学院、基本功、通用咒式；材质是羊皮纸、黄铜尺、练习用木牌；动作是翻、找、理、练。

### 6.7 跨系共用字

| 字 | 用法 | 注意 |
|---|---|---|
| **回** | 回响、回火、回潮、回岩、回流、回震 | 表示“返回 / 再次 / 反弹”；不要所有系都用，避免疲劳 |
| **循** | 循环、循环抽牌 | 表示“资源循环”；目前是通用牌 |
| **印** | 印记、刻印、徽记 | 表示“标记 / 记录”；不要与“环印”（赛事血量）混淆 |
| **刻** | 刻度、刻印、蚀刻 | 表示“计量 / 刻入”；不要滥用 |
| **源** | 万毒之源、源 | 表示“源头”；目前是毒系专精 |
| **心** | 潮汐之心、余烬心脏、壁垒之心 | 表示“核心 / 心脏”；多用于专精或路线传奇 |
| **之** | 生命之泉、疾风之刃、大地之握 | 古典 / 史诗语域；普通牌少用 |

## 8. 专精、传奇、5 层与路线传奇

### 8.1 专精强卡（环相）

**规则**：定环时凝成的元素法相；名字要像“一个巨大的、唯一的形相”，不是一张普通法术。

| 系 | 现有 | 构词 | 感觉 |
|---|---|---|---|
| 火 | 炽焰王冠 | 元素意象 + 权威名词 | 一顶会滴落余烬的王冠 |
| 水 | 潮汐之心 | 元素意象 + 核心名词 | 一颗有潮汐往复的水心 |
| 土 | 不周山 | 专有山名 | 一座没有合拢的巨山 |
| 风 | 天岚 | 天象专名 | 一圈天空之环 |
| 毒 | 万毒之源 | 程度 + 源头 | 一眼不断冒孢子的活泉 |

**新专精命名建议**：

- 公式 A：[元素意象] + 冠 / 心 / 山 / 岚 / 源 / 座 / 眼 / 庭。
- 公式 B：一个 2–3 字的专有自然名（如“不周山”“天岚”）。
- 不要用动词；不要用“术”“咒”“击”；不要超过 4 字。
- 名字必须能直接画成一个巨大的背景形相。

### 8.2 5 层特殊传奇

**规则**：纯层数加速，不定义路线；名字要像“一次性发生的大规模自然现象”。

| 系 | 现有 | 字数 | 意象 |
|---|---|---|---|
| 火 | 燎原 | 2 | 火势铺开 |
| 水 | 深渊潮 | 3 | 深水涨潮 |
| 土 | 山崩 | 2 | 山体崩落 |
| 风 | 飓风 | 2 | 大风盘旋 |
| 毒 | 瘟潮 | 2 | 枯萎蔓延 |

**新 5 层命名建议**：

- 2–3 字；自然现象 / 天象 / 地质事件。
- 不要带角色名；不要带路线机制；不要用“之”。
- 例：如果是雷系（暂缓），可以叫“落雷”“雷暴”；不要叫“雷神之怒”。

### 8.3 路线传奇

**规则**：路线传奇的名字 = 牌组名 = 流派名。三者必须一致，不要分别起名。

| 系 | 路线传奇 | 字数 | 构词 |
|---|---|---|---|
| 火 | 燃烧血统 | 4 | 意象 + 系统 |
| 火 | 余烬之核 | 4 | 资源 + 核心 |
| 火 | 灰烬循环 | 4 | 意象 + 机制 |
| 水 | 血潮 | 2 | 意象 |
| 水 | 生命之泉 | 4 | 意象 + 载体 |
| 水 | 潮汐回响 | 4 | 资源 + 动作 |
| 土 | 反震岩核 | 4 | 动作 + 核心 |
| 土 | 大地之握 | 4 | 意象 + 动作 |
| 土 | 壁垒之心 | 4 | 核心 + 核心 |
| 风 | 风痕 | 2 | 资源 |
| 风 | 疾风之刃 | 4 | 意象 + 载体 |
| 风 | 穿云箭 | 3 | 动作 + 载体 |
| 毒 | 蚀命 | 2 | 动作 + 对象 |
| 毒 | 蚀骨 | 2 | 动作 + 对象 |
| 毒 | 毒爆 | 2 | 资源 + 动作 |

**新路线命名建议**：

- 2–4 字；要么是“流派 / 系统”（燃烧血统、潮汐回响），要么是“核心意象”（生命之泉、穿云箭）。
- 必须能当牌组名；玩家会说“我玩燃烧血统”，不会说“我玩火焰强化流”。
- 不要用“火系一”“水系二”这种工程代号做正式名；工程代号只用于文件夹。
- 一条路线只对应一张路线传奇；名字不要与专精强卡重复。

### 8.4 通用传奇

**规则**：通用传奇是环藏秘典，不属于任何元素；名字要像“一件被禁止 / 被珍藏的东西”。

| 现有 | 字数 | 类型 |
|---|---|---|
| 禁忌知识 | 4 | 知识 |
| 禁咒目录 | 4 | 书 / 目录 |
| 魔力契约 | 4 | 契约 |
| 元素熔炉 | 4 | 器物 |
| 魔法阵核心 | 5 | 世界核心 |
| 战神徽记 | 4 | 徽记 |
| 守护者壁垒 | 5 | 防御概念 |
| 时光倒流 | 4 | 时间现象 |

**新通用传奇命名建议**：

- 2–5 字；优先“书 / 目录 / 契约 / 熔炉 / 核心 / 徽记 / 壁垒 / 时光”这类“被收藏的东西”。
- 不要带元素词；不要带角色名；不要用“无敌”“终极”“神级”。
- 可以稍微越界（时间、知识、契约），因为它们是环藏秘典，不是普通咒式。

## 9. 通用牌命名

通用牌是学院基本功，不属于任何元素。

### 9.1 规则

- 不提供附魔层；名字不要带元素词。
- 语域偏“课堂 / 手册 / 练习”：攻击强化、防御强化、护盾、检索附魔、重洗、翻阅、速读、整理。
- 可以使用功能词，但不要写成规则文本：用“翻阅”不用“抽牌数量增加”；用“破甲”不用“目标防御降低”。
- 通用牌也可以有画面：锋刃、坚壁、盾墙、命运检索、灵感涌现、破军、永恒壁垒。
- 基础牌可以最平实：攻击强化、防御强化、护盾、重洗；它们是玩家的“母语”，不要花哨。

### 9.2 命名梯度

| 层级 | 例子 | 感觉 |
|---|---|---|
| 基础 | 攻击强化、防御强化、护盾、重洗 | 学徒手册 |
| 普通 | 翻阅、速读、寻物、利刃、壁障、小盾、包扎 | 课堂练习 |
| 稀有 | 小检索、大检索、循环、锋刃、坚壁、铁壁、盾墙、愈合 | 正式咒式 |
| 史诗 | 通晓、灵感涌现、命运检索、破军、永恒壁垒、圣盾、治愈洪流 | 大魔法师的手笔 |
| 传奇 | 禁忌知识、禁咒目录、魔力契约、元素熔炉、魔法阵核心、战神徽记、守护者壁垒、时光倒流 | 环藏秘典 |

### 9.3 通用牌不要做的事

- 不要用“火 / 水 / 土 / 风 / 毒”开头；那会抢元素身份。
- 不要用“环 / 宴 / 庭 / 守 / 主 / 灵”做随手卡名；那是世界核心词。
- 不要用“神圣 / 恶魔 / 诅咒”等强阵营词；通用牌是中立工具。
- 不要用“超级 / 终极 / 究极 / 无敌”；那是另一款游戏。

## 10. 效果与名字的对应

### 10.1 三条原则

1. **名字提示机制，但不复述机制。**
   - 好：余烬刻度（数余烬）、灰烬账本（记录消耗）、潮汐回廊（存储 / 返还）、风痕刻印（叠痕）、固毒 / 延毒（维持 / 延长）。
   - 坏：余烬数量检测并获取一层余烬（这不是名字）。
2. **复杂效果，命名画面，不命名公式。**
   - 例如“消耗全部毒层造成 2.8 倍毒伤”叫“毒潮”，不叫“毒层倍率爆发”。
3. **同根同效，异根异效。**
   - 同根家族的效果必须相关；如果效果无关，换一个词根，避免玩家误判。

### 10.2 名字与效果的对应表

| 名字类型 | 例子 | 玩家预期 | 注意 |
|---|---|---|---|
| 资源 + 计量 | 余烬刻度、风痕刻印 | 数资源、叠层数 | 不要让效果与资源无关 |
| 容器 + 内容 | 毒瓶、毒囊、火种库、高压弹仓 | 储存 / 释放 | 可以是“下一次”爆发 |
| 动作 + 对象 | 破甲、裂伤、蚀骨、穿云 | 直接作用于对象 | 不要用来做纯防御 |
| 状态 + 核心 | 慢燃、静水、不坏壁垒 | 延迟 / 持续 / 不破 | 效果要符合状态 |
| 专名 / 流派 | 燃烧血统、潮汐回响、不周山 | 一套完整玩法 | 不能只是数值卡 |
| 自然现象 | 燎原、山崩、飓风、瘟潮 | 大规模、一次性 | 适合 5 层传奇 |
| 权威 / 法相 | 炽焰王冠、潮汐之心、万毒之源 | 巨大的元素形相 | 适合专精 |

### 10.3 误导性名字

| 名字 | 问题 | 建议 |
|---|---|---|
| 治愈之刃 | 名字像治疗，实际是伤害 | 血刃 / 蚀创 |
| 火墙（现有例外） | 名字像伤害墙，实际是防御 / 净化 | 保留，但卡面插画要画“烧尽杂质的火墙”，不是火海 |
| 静水（现有） | 名字像防御，实际是吸血 / 伤害转化 | 保留；插画要画“静止水面下的暗流” |
| 毒针 / 毒刺 / 毒牙 | 都是毒系，效果不同 | 用“针 / 刺 / 牙”区分：针=上毒，刺=伤害，牙=数值 |
| 深渊（现有） | 名字像邪恶，实际是水系防御 | 插画用深海、压力、暗流，不要触手与恶魔 |

## 13. 新卡命名审查清单

### 13.1 形式

- [ ] 2–5 字？传奇不超过 5 字？
- [ ] 放进卡框顶部，是否还剩留白？
- [ ] 是否没有标点、数字、英文？
- [ ] 是否读起来顺口、没有生僻字堆叠？

### 13.2 画面

- [ ] 能否直接交给美术，说“画这个”？
- [ ] 是否是一个具体物件 / 动作 / 现象，而不是抽象概念？
- [ ] 是否与效果有直觉关联，但不复述规则？

### 13.3 元素

- [ ] 是否使用了对应元素的词库？
- [ ] 去掉元素前缀，还能看出是哪一系吗？
- [ ] 是否避免了另一系的专属词（火用冰、水用毒、土用雷等）？
- [ ] 毒系是否避免了邪恶 / 恐怖词？

### 13.4 语域

- [ ] 普通像普通，稀有像稀有，史诗像史诗，传奇像传奇？
- [ ] 传奇是否像一个专名 / 流派 / 法相 / 自然现象？
- [ ] 是否避免了“终极 / 超级 / 无敌 / 神级”？

### 13.5 查重

- [ ] 全卡库搜索：是否已有同名？
- [ ] 是否已有同根但效果无关的牌？
- [ ] 是否与现有牌名只差一个字、效果却完全不同？
- [ ] 同根家族的效果是否相关？

### 13.6 世界观

- [ ] 是否避免了现代 / 军事 / 科幻词？
- [ ] 是否避免了现实宗教 / 政治 / 疾病隐喻？
- [ ] 是否避免了滥用“环 / 宴 / 庭 / 守 / 主 / 灵”？
- [ ] 火系的“弹 / 仓 / 火药”是否仍被理解为咒式容器，而不是火器？

### 13.7 记忆点

- [ ] 听一遍能复述吗？
- [ ] 一局之后还能记住吗？
- [ ] 能否用来给牌组命名？
- [ ] 是否有“我想打这张牌”的冲动？

### 13.8 英文

## 14. 命名工作流

### 14.1 五步法

1. **写效果**：用一句话写清楚这张牌做什么。
2. **打标签**：元素、稀有度、路线、资源（余烬 / 潮汐 / 护盾 / 风痕 / 毒层）、节奏（立即 / 下一发 / 整场）。
3. **选画面**：从词库挑 3 个意象；问“这张牌如果是一幅画，画里是什么？”
4. **造名字**：用公式生成 5 个候选；每个不超过 5 字。
5. **过审查**：用第 13 节清单逐项检查；读出声；查重；定稿。

### 14.2 定稿后

- 把卡名、英文名、效果、稀有度、路线写进对应元素卡表。
- 更新本文第 7 节的“现有卡名谱系”（如果新增了词根或家族）。
- 通知美术：卡名、元素、构图关键词、色板、安全区。
- 如果卡名会影响牌组名 / 路线名，先确认路线传奇名是否一致。

## 15. 常见错误

| 错误 | 例子 | 为什么不行 | 改法 |
|---|---|---|---|
| 通用 RPG 名 | 火焰球、冰霜箭、雷神之怒 | 没有本作身份，像任何游戏 | 用本作词库与画面 |
| 规则文本当名字 | 风之速度提升、毒层增加术 | 像说明书，不像卡牌 | 风步、固毒、延毒 |
| 太长 | 烈焰焚烧一切、绝对无敌守护 | 卡框放不下，读起来累 | 燎原、永恒壁垒 |
| 元素前缀堆叠 | 火系攻击、火系防御、火系强化 | 像工程标签，不像卡名 | 火舌、火墙、高温炉心 |
| 毒系邪恶化 | 邪恶毒咒、死亡瘟疫 | 破坏“毒系不是邪恶”的设定 | 蚀命、腐息、瘟潮 |
| 现代 / 军事 | 火焰枪、毒气弹、魔法导弹 | 破坏中世纪基调 | 火舌、毒瓶、法弹（术语） |
| 近义撞车 | 火焰弹 / 火球 / 火弹 | 玩家分不清，卡库混乱 | 选一个家族，其余改掉 |
| 传奇太普通 | 大火球、超级护盾 | 没有“环藏秘典”的分量 | 燎原、永恒壁垒 |
| 语域混搭 | 火之高兴、岩盾盾盾 | 破坏沉浸感 | 按稀有度语域重命名 |
| 滥用世界词 | 环之打击、环宴冲击 | 稀释“环”的品牌 | 碎岩印记、回震岩甲 |
| 名字误导 | 治愈之刃（实际伤害） | 玩家预期错误 | 血刃、蚀创 |
| 文化错位 | 随便一张普通牌叫不周山 | 专名被稀释 | 不周山只给土专精 |
| 英文直译 | God of War Sigil | 宗教 / 版权感，且太通用 | Warbrand |
| 没有查重 | 新卡叫“余火”，效果却与现有余火无关 | 玩家混淆 | 换词根或改效果 |

## 16. 例外与保留名

以下名字有历史或设定原因，**保留不改**；新卡不要模仿它们的“越界”，除非有明确理由。

| 名字 | 例外原因 | 美术注意 |
|---|---|---|
| **火墙** | 名字像伤害墙，实际是防御 / 净化；火墙在设定中是“烧尽杂质的火墙” | 画火墙净化毒与诅咒，不要画火海 |
| **静水** | 名字像防御，实际是吸血 / 伤害转化；取“静水深流” | 画静止水面下的暗流，不要画盾 |
| **弹仓 / 弹头 / 火药 / 导火索** | 火系的黄铜 / 陶制咒式容器，不是火器 | 画药囊、铜壳、引线、火漆；不要画枪管、扳机、子弹 |
| **不周山** | 土系专精的专有山名；设定中是“没有合拢的巨山” | 画断顶巨山与未闭合的环，不要画中国寺庙 |
| **天岚** | 风系专精的天象专名 | 画天空之环与风痕，不要画人形 |
| **万毒之源** | 毒系专精的活泉；不是恶魔 | 画菌丝、孢子、泉水，美丽而微微不安；不要画骷髅与毒气 |
| **禁忌知识 / 禁咒目录** | 通用传奇的“禁书” | 画旧书、锁链、蜡封；不要画骷髅与恶魔 |
| **战神徽记** | 通用传奇的“战意徽记”；不是具体神祇 | 画黄铜徽章、剑痕、绶带；不要画神像与十字 |
| **守护者壁垒 / 永恒壁垒 / 圣盾** | “圣”是古语“神圣”，不是现实宗教 | 画光、石、盾；不要画十字、天使、教堂 |
| **时光倒流** | 通用传奇的时间魔法 | 画沙漏、星盘、逆流的光；不要画科幻时间机 |
| **深渊 / 深渊潮** | 水系的“深海”，不是地狱 | 画深水、压力、暗流；不要画触手、恶魔、眼睛 |
| **瘟潮 / 疫病** | 毒系的自然枯萎，不是生化武器 | 画孢子、菌丝、枯叶；不要画瘟疫医生、骷髅、绿毒气 |
| **魔法阵核心** | 世界核心的直称；通用传奇 | 可以复用万环之心的环纹；不要画电脑芯片 |
| **元素熔炉** | 炼金 / 咒式熔炉 | 画黄铜坩埚、玻璃、火漆；不要画工业高炉 |
| **魔力契约** | 魔法契约 | 画羊皮纸、蜡封、签名；不要画恶魔契约 |

## 17. 一页速查

### 17.1 七个问题

1. 几个字？2–4，传奇最多 5。
2. 是一幅画吗？不是说明书。
3. 哪一系的词？去掉前缀还认得出吗？
4. 什么稀有度？语域对吗？
5. 撞名了吗？同根同效吗？
6. 破坏世界观吗？现代 / 军事 / 邪恶 / 宗教？
7. 读得顺、记得住、说得出吗？

### 17.2 五系一句话

- **火**：热金属、余烬、黑烟、黄铜；压、烧、淬、敲。
- **水**：深青、玻璃、珍珠、茶；流、回、涌、沉。
- **土**：花岗岩、苔藓、石灰、陶；叠、压、裂、撑。
- **风**：天青、羽毛、银、云；掠、切、追、回。
- **毒**：梅紫、橄榄、酸黄、菌菇；渗、蚀、酿、腐、生。

### 17.3 最后一条

**如果名字需要一段解释才能听懂，它就不是好名字。**
**如果名字让你立刻想画出来，它多半是对的。**
