# Magicians! 世界观与命名总纲

- 版本：lore v0.1（2026-10-22）
- 用途：为剧情、卡牌命名、美术素材、UI 文案、宣传物料提供统一口径
- 边界：**本文不是规则文档**。与 `../overview.md`、`../combat/*`、`../cards/*` 冲突时，以规则与卡表为准；本文只回答“为什么”和“看起来、听起来是什么”

## 1. 一句话世界观

**每年秋天，散落在大陆各处的老同学回到万环之心，在黄昏的魔法阵里互相发射附魔飞弹，争夺“这一年谁来照看整片大陆最大的魔法阵”。**

- **争环，不争命。**
- **环不说话，但环记得。**
- 魔法是手艺，不是神迹；大魔法师是手艺最好、也最会互相拆台的那群人。

## 2. 核心设定速查

| 项目 | 设定 |
|---|---|
| 大陆 | **环洲**，地貌像一枚被摊平的环；中央是环心原，五条地脉伸向五域 |
| 最大的魔法阵 | **万环之心**，位于环心原中央，连接全大陆的环 |
| 年度聚会 | **环宴**，每年环月在**环庭**举行，持续到决出环主 |
| 争夺方式 | **环斗**：两两进入环场，用咒册与附魔飞弹对战；不取性命 |
| 年度冠军 | **环主**，获得万环之心一年的照看权，并负责下一届环宴 |
| 主办与裁判 | **守环人**，现任是柯温；执行与报分由**环灵·阿环**协助 |
| 魔法来源 | 地脉中的**脉息**；魔法师通过**法印**与**咒册**读取、储存、释放 |
| 五系 | 火、水、土、风、毒，学界称**五脉**；毒系是医药、发酵与衰败的学问，不是邪恶 |
| 非致死 | 环场把致命伤害转为**战息**；战息耗尽只是退场。赛事扣的是**环印**，环印耗尽只是退环 |
| 幽灵对局 | **残响**：环从**环藏**中重放最近退环者的咒册，本人坐在场边点评 |
| 科技水平 | 参考欧洲中世纪：水车、风车、玻璃、黄铜、羊皮纸、手抄本；没有枪炮、蒸汽机与印刷机 |
| 基调 | 温暖、手作、节日感、朋友间的认真较量；不黑暗、不血腥、不搞世界末日 |

## 3. 三个不可动摇的基调

1. **争环，不争命。**
   环斗是为了不用战争。输赢很重要，但输的人还能笑着吃饭，赢的人要负责洗杯子。
2. **环不说话，但环记得。**
   环不显灵、不说话、不赐福；它只是古老、精确、记性极好。所有“神迹”都有可解释的机制。
3. **魔法是手艺。**
   魔法师更像铁匠、医生、抄写员、建筑师、邮差和酿酒师，而不是天选之人。谁的手艺好，谁的咒册顺，谁就赢。

## 5. 设定分级（Canon）

写新内容时，先确认它属于哪一级。

### 5.1 固定（与规则或核心愿景绑定，不要改）

- 四人淘汰、两两对战、环印 50、战息 1000。
- 每抽 5 页、3 点咏息、不累积。
- 五系：火、水、土、风、毒；毒系不是邪恶阵营。
- 同系 3 张定环；专精后不再出现其他系附魔。
- 传奇只能三选一；路线传奇全牌组最多 1 张。
- 三人阶段使用残响；残响来自最近退环者。
- 环斗不取性命；赛事是年度聚会，不是战争。

### 5.2 建议（本文提出，可随创作调整）

- 地名：环洲、环心原、环庭、赤炉丘、澜泽、磐岭、长风原、雾孢泽。
- 专名：万环之心、环宴、环主、守环人、环灵·阿环、环藏、环律、残响。
- 历史：刻环者、断环之夜、争环之战、环约。
- 五席角色与守环人的性格、视觉母题。
- 五系的文化气质、饮食、产业与色彩。

### 5.3 开放（留给后续剧情/赛季/玩家共创）

- 刻环者到底去了哪里；万环之心是不是“门”。
- 玩家是否固定为某一席，还是每年新受邀的来访大魔法师。
- 第一届环宴的具体年份；是否做“第一百届”特别剧情。
- 环洲之外是否还有其他大陆与魔法体系。
- 五席的姓名是否替换为你与朋友们的化身。

## 6. 怎么用这份文档

### 写一张新卡

1. 先读 [naming-guide.md](naming-guide.md) 的“七条硬规则”和对应元素的词库。
2. 用“画面命名法”：先想这张牌如果是一幅画，画里是什么；不要用规则文本当名字。
3. 查重：现有卡名谱系在 naming-guide 第 7 节。
4. 检查稀有度语域：普通要日常，传奇要像专名。
5. 最后再检查英文名与卡框宽度。

### 出一张图

1. 先读 [visual-guide.md](visual-guide.md) 的“风格一句话”和五系色板。
2. 角色图先锁定剪影、道具、主色；场景图先锁定时间、天气、光源。
3. 卡牌插画顶部与底部留空，文字在引擎里合成；**不要让 AI 画字**。
4. 同一批图使用同一套线宽、光向、色板；先做 style sheet，再做量产。

### 写一段剧情

1. 先读 [world.md](world.md) 的“环宴流程”和“语调边界”。
2. 冲突优先来自：旧同学梗、赌约、借书不还、配对尴尬、谁负责洗碗。
3. 不要引入魔王、灭世、血腥祭祀；如果要神秘感，用“环记得”而不是“环发怒”。

### 做 UI 文案

1. 规则术语优先保证可读性，不要为了风味把“费用”改成“咏息”导致玩家看不懂。
2. 世界观说法用于：卡牌风味文本、加载界面、教程旁白、成就名、战斗播报。
3. 对照 [naming-guide.md](naming-guide.md) 第 13 节的术语映射表。

## 7. 命名速查

| 概念 | 推荐写法 | 备注 |
|---|---|---|
| 大陆 | 环洲 | 不要写“环大陆” |
| 最大的魔法阵 | 万环之心 | 全名；口语可叫“大环” |
| 年度聚会 | 环宴 | 不要写“环赛”“环节” |
| 举办地 | 环庭 | 环心原上的阶梯城镇 |
| 冠军 | 环主 | 今年的环主；历任环主 |
| 主办者 | 守环人 | 不是“环主”；守环人通常不参赛 |
| 引导精灵 | 环灵·阿环 | 英文可用 Halo |
| 赛事血量 | 环印 | UI 可保留“赛事血量” |
| 战斗生命 | 战息 | UI 可保留“生命” |
| 疲劳 | 逆息 | 1500 环刻后开始 |
| 幽灵 | 残响 | 来自环藏，不是亡魂 |
| 自动模式 | 托咏 | 玩家写咏序，环代为执行 |
| 手动模式 | 亲咏 | 玩家自己打牌 |
| 卡牌 | 咒式 / 咒式页 | 卡面、图鉴、收藏 |
| 牌组 | 咒册 | 构筑、存档、加载 |
| 附魔层 | 环纹 | 法印上的同心环 |
| 专精 | 定环 | 三纹锁环 |
| 专精强卡 | 环相 / 法相 | 冠、心、山、岚、源 |
| 传奇 | 环藏秘典 | 三页秘藏，选一页 |

## 9. 维护规则

- 新增地名、角色、卡名先查重，再写入对应文件。
- 规则改动不改本文；本文只改“解释方式”。
- 旧设定不直接删除，移入 `archive/` 或在本文件标注“已废弃”。
- 角色姓名默认可替换；**称号、剪影、色板、道具**是稳定资产。
- 任何与规则冲突的漂亮设定，一律让位给规则；规则之后再找更漂亮的解释。
