# 美术方向与素材指南

- 版本：lore v0.1
- 上游：[README.md](README.md)、[world.md](world.md)、[characters.md](characters.md)
- 用途：2D 美术、UI、特效、宣传物料、AI 绘图提示词
- 原则：**先统一，再量产。** 先做 style sheet，再做卡牌与场景。

---

## 1. 风格一句话

**十五世纪欧洲手抄本插画 × 黄铜天文仪器 × 秋日节庆市集。**

- 手作感：羊皮纸、鹅毛笔、木刻线、蜡封、装订线。
- 精密感：黄铜刻度、同心圆、星盘、齿轮般的环纹。
- 节日感：灯笼、布幡、食物、烟火、朋友间的笑声。
- 魔法感：光是“被引导的”，不是“爆发的”；法术像仪器与手艺，不像超级英雄。

### 1.1 三个关键词

1. **Warm**：暖光、暖材质、暖关系。
2. **Handmade**：看得见笔触、纸张纹理、金属锤痕。
3. **Readable**：剪影清楚、色块明确、卡面信息一眼可读。

### 1.2 不要的方向

- 黑暗奇幻、血腥、哥特恐怖、骷髅、恶魔、献祭。
- 赛博、霓虹、全息、科幻 HUD、蒸汽朋克齿轮堆。
- 日式二次元、韩式厚涂、写实 3D、照片级渲染。
- 通用手游卡牌：满屏发光、复杂到看不清的边框、过度渐变。
- 任何 AI 生成的文字、签名、水印、logo。

## 2. 视觉支柱

### 2.1 材料

| 材料 | 用途 | 画法 |
|---|---|---|
| 羊皮纸 / 犊皮纸 | 卡面、书页、地图、UI 底 | 暖米色，细纤维，边缘微旧；不要脏污 |
| 黄铜 | 环、刻度、费用币、边框角 | 暖金，哑光，有锤痕与氧化；不要镜面金 |
| 玻璃 | 水系法印、药瓶、环场 | 透明但有厚度，边缘偏青；不要塑料感 |
| 羊毛 / 亚麻 | 服装、披肩、毯子 | 粗织纹理，可见褶皱；不要丝绸反光 |
| 皮革 | 工具带、书封、护腕 | 磨旧、有划痕；不要亮面皮衣 |
| 苔藓 / 菌丝 | 土系、毒系环境 | 湿润、有体积；不要荧光 |
| 炭火 / 余烬 | 火系光源 | 橙红核心，黑烟外缘；不要纯黄爆炸 |

### 2.2 光

- 主光方向统一为**左上**，除非场景有明确光源（环光、炉火、灯笼）。
- 魔法光从**下往上**照角色，像站在发光的井口；这会让环纹与脸部轮廓更神秘。
- 环宴场景用**黄金时刻 + 灯笼暖光**；夜间用**蓝调环境 + 暖色点光**。
- 避免平光、影棚光、纯黑背景；用环境色包裹角色。

### 2.3 线

- 主轮廓：清晰的深色线，略粗；内部结构：细线。
- 参考木刻版画的排线，但不要过度密集；保持可读。
- 卡牌插画可以有线，也可以无线；同一批卡必须统一。
- 不要用纯黑描边；用深褐、墨蓝或元素深色。

### 2.4 比例

- 角色：7–7.5 头身，半写实风格化；手大、脚稳、剪影清楚。
- 阿环：手掌大小；在 UI 里可以放大，但比例不变。
- 法术：法弹约人头大小；环相约 2–3 层楼高；不要大到遮住角色。
- 场景：人物与建筑比例真实；魔法阵的尺度要能让人站进去。

## 3. 五系色板与形状语言

### 3.1 色板

| 系 | 主色 | 辅色 | 高光 | 深色 | 点缀 |
|---|---|---|---|---|---|
| **火** | `#C8402A` 朱红 | `#E8892B` 余烬橙 | `#FFF1D0` 火星白 | `#2B1D1A` 炭黑 | `#F2C14E` 黄铜 |
| **水** | `#1F5C63` 深青 | `#3E8E8A` 海沫 | `#E9F3EE` 珍珠 | `#173B40` 渊青 | `#D9A441` 黄铜 |
| **土** | `#6B5B3E` 赭石 | `#8A9A5B` 苔藓 | `#C9BFA3` 石灰 | `#3E3A32` 深褐 | `#B87333` 铜 |
| **风** | `#6FA8C9` 天青 | `#B8D8E8` 雾蓝 | `#F2F5F7` 云白 | `#5C6B75` 青灰 | `#E3C567` 淡金 |
| **毒** | `#5B3A5E` 梅紫 | `#7A8B4A` 橄榄 | `#B7C66A` 酸黄 | `#2E2A24` 泥炭 | `#C9A227` 琥珀 |
| **中立 / 环** | `#2E3A4A` 墨蓝 | `#B08D3F` 黄铜 | `#EFE3C8` 羊皮纸 | `#2B2620` 墨 | `#8C2F39` 火漆红 |

使用规则：

- 每张图主色不超过 2 个，辅色不超过 2 个，点缀 1 个。
- 元素色占 60%，中性色占 30%，点缀 10%。
- 毒系不要用荧光绿；用梅紫 + 橄榄 + 酸黄，酸黄只做小面积高光。
- 火系不要用纯黄到纯红的渐变；用“暗红—橙—火星白”的三段，边缘带黑烟。
- 水系不要用纯蓝；用青绿与珍珠白，显得像湖水而不是天空。
- 土系不要用沙漠黄；用赭石、苔藓、石灰，显得湿润、有生命。
- 风系不要用纯白；用天青、雾蓝、云白，保持空气感。

### 3.2 形状语言

| 系 | 主形状 | 运动 | 材质 | 图标 |
|---|---|---|---|---|
| **火** | 向上的三角、火花、放射线 | 爆开、上升、飘散 | 热金属、炭、黄铜 | 三簇余烬围成的冠 |
| **水** | 新月、S 形曲线、同心涟漪 | 流动、回卷、落回 | 玻璃、珍珠、湿石 | 一滴水中含一圈涟漪 |
| **土** | 六边形、堆叠方块、厚弧 | 堆叠、沉降、裂开 | 花岗岩、苔藓、陶 | 未闭合的石环 |
| **风** | 螺旋、细弧、羽毛、断线 | 扫过、切开、回旋 | 丝绸、羽毛、银 | 三道风痕穿过一枚环 |
| **毒** | 分枝菌丝、气泡、点状孢子 | 蔓延、绽放、溶解 | 玻璃罐、苔藓、陶 | 一朵菌盖托着一滴露 |
| **环 / 中立** | 同心圆、刻度、星盘环 | 旋转、对齐、锁定 | 黄铜、羊皮纸、光 | 双层环 + 中央光点 |

图标要求：

- 单色或双色，能在 32×32 像素下辨认。
- 不依赖文字；不要用“火”“水”等汉字做图标。
- 元素图标与卡框、UI、特效使用同一套形状语言。

## 4. 卡牌视觉系统

### 4.1 卡面结构

```text
+--------------------------------------------------+
|  [费用]        卡牌名称              [元素符文]  |  <- 顶部 10-12%
+--------------------------------------------------+
|                                                  |
|                                                  |
|                 插画安全区                       |  <- 中部 55-60%
|          （顶部与底部留空，文字后合成）          |
|                                                  |
|                                                  |
+--------------------------------------------------+
|  效果文本 / 风味文本                             |  <- 底部 22-28%
|                                                  |
|  [稀有度]                            [系列环]    |
+--------------------------------------------------+
```

- **名称**：2–4 字最佳，最多 5 字；超过 5 字会压到费用与符文。
- **费用**：左上，黄铜币形，内嵌数字；不要用红色宝石或蓝色法力滴。
- **元素符文**：右上，使用五系图标；通用牌用环/星盘图标。
- **稀有度**：左下，宝石或金属标记；不要用彩色边框区分（边框要统一）。
- **系列环**：右下，一枚小环；不同系列用不同内纹。
- **插画**：不要画卡框、名称、效果文本；这些在引擎里合成。
- **安全区**：插画顶部留 10%，底部留 20%；主体在中央 70%。

### 4.2 稀有度

| 稀有度 | 边框 | 材质 | 颜色 | 动效（游戏内） |
|---|---|---|---|---|
| **普通** | 单层木刻线 | 羊皮纸 | 1 个元素辅色 | 无 / 轻微纸张呼吸 |
| **稀有** | 双层线 + 黄铜角钉 | 羊皮纸 + 压纹 | 2 个元素色 | 卡面微光 |
| **史诗** | 彩绘玻璃内嵌 + 金线 | 玻璃 + 羊皮纸 | 3 个元素色 | 边框流光 |
| **传奇** | 全画框 + 蜡封 + 专属法印 | 羊皮纸 + 金箔 + 蜡 | 4+ 色 | 环纹旋转、余烬飘散 |
| **路线传奇** | 全画框 + 角色母题 | 同上 + 角色剪影 | 路线主色 | 角色环相若隐若现 |
| **专精强卡** | 五环锁 + 环相 | 黄铜 + 玻璃 | 元素主色 + 金 | 五环逐层锁定 |

注意：

- 普通与稀有的卡框必须“安静”，让插画说话；不要每张都发光。
- 传奇可以华丽，但文字区必须可读；不要把金线压在字上。
- 路线传奇的“角色母题”是暗示，不是把角色画进每一张卡；例如燃烧血统只画锻锤与余烬，不画伊格娜本人。

### 4.3 卡背

- 统一卡背：深墨蓝底 + 黄铜同心环 + 中央五系小图标围成一圈。
- 环心留空，放系列标志；不要放角色脸。
- 卡背要耐看、低对比，避免在桌上抢卡面。

### 4.4 文字与字体

- 中文标题：宋体/楷体风格的衬线字，略粗；不要用哥特黑体或书法狂草。
- 中文正文：高可读性宋体或黑体；字重中等；行距充足。
- 英文标题：Humanist serif / small caps；正文用易读 serif 或 sans。
- 数字：黄铜币内的数字用衬线字；不要用科幻字体。
- 效果文本：关键词加粗或用元素色；不要整段变色。
- 不要在卡面使用超过 2 种字体。

## 5. 场景与色彩脚本

### 5.1 环庭

| 时段 | 天空 | 主光 | 色板 | 情绪 |
|---|---|---|---|---|
| **清晨** | 淡金、薄雾 | 低角度暖光 | 羊皮纸、雾蓝、黄铜 | 安静、准备开始 |
| **正午** | 清澈、少云 | 顶光偏硬 | 石灰、天青、赭石 | 忙碌、配环公布 |
| **黄昏** | 橙红到墨蓝 | 环光 + 灯笼 | 余烬橙、深青、黄铜 | 环斗、热闹、黄金时刻 |
| **夜晚** | 深墨蓝、星 | 灯笼 + 环光 | 墨蓝、琥珀、火漆红 | 宴会、复盘、亲密 |

环庭构图：

- 环形台地层层向上，中央是万环之心；用透视强调“所有人围着同一个中心”。
- 布幡、灯笼、摊位从前景延伸到中景，制造节日密度。
- 观众坐在台地边缘，脚悬在空中，手里拿食物；不要画成竞技场看台。
- 环场是半透明半球，不要画成实心光墙；能看到里面的影子与飞弹轨迹。

### 5.2 五域

| 区域 | 时间 | 天气 | 主色 | 关键元素 | 情绪 |
|---|---|---|---|---|---|
| **赤炉丘** | 黄昏 | 干燥、烟尘 | 朱红、炭黑、黄铜 | 窑炉、烟囱、火星、红岩 | 热、响、亲切 |
| **澜泽** | 清晨 | 薄雾、细雨 | 深青、海沫、珍珠 | 运河、茶梯田、乌篷船、玻璃棚 | 静、润、含蓄 |
| **磐岭** | 正午 | 晴朗、强阴影 | 赭石、苔藓、石灰 | 断崖城、根桥、采石场、晶洞 | 稳、古、可靠 |
| **长风原** | 下午 | 大风、云影 | 天青、雾蓝、云白 | 风车、风筝、高草、断崖 | 自由、轻、远 |
| **雾孢泽** | 黄昏 | 潮热、孢子雾 | 梅紫、橄榄、酸黄 | 菌林、药田、浮岛、玻璃罐 | 温柔、繁茂、微微不安 |
| **环心原** | 任意 | 清澈、高海拔 | 羊皮纸、黄铜、墨蓝 | 万环之心、环庭、脉路 | 中心、归属、仪式 |

### 5.3 环场

- 视角：观众视角或选手视角；不要俯视到看不清人。
- 构图：两座咏台在画面左右，法弹在中央飞行；观众在前景边缘虚化。
- 环场地面：深色石面 + 黄铜刻度 + 发光环纹；不要镜面反射。
- 环场边界：半透明玻璃质感，有细微刻度与符文；被击中时出现裂纹与光。
- 背景：环庭台地、灯笼、布幡；不要让背景比环斗更亮。

## 6. UI 设计

### 6.1 原则

- **可读性优先**：规则术语不要为了风味改成生僻词；世界观说法放在风味文本里。
- **材料统一**：羊皮纸、黄铜、玻璃、蜡封；不要出现塑料、霓虹、全息。
- **信息层级**：当前行动 > 可用费用 > 手牌/浮页 > 对手状态 > 日志。
- **动效克制**：翻页、墨迹、环纹旋转、光线描边；不要粒子爆炸满屏。

### 6.2 关键界面

| 界面 | 视觉概念 | 关键元素 |
|---|---|---|
| **战斗主界面** | 一本摊开的咒册 + 一枚星盘 | 浮页、咏息币、环刻时间轴、双方战息、法印环纹 |
| **环刻时间轴** | 黄铜星盘外圈 | 100 刻度、抽牌标记、发射标记、当前刻度指针 |
| **法印面板** | 同心圆环纹 | 五系颜色、层数、专精锁、异种环纹（最多 2 层） |
| **构筑界面** | 册廊 / 抄写台 | 咒册、待选页、焚页炉、蜡封、页签 |
| **传奇三选一** | 环藏三页秘典 | 三页悬浮、金线、蜡封、环光；选中后化入法印 |
| **赛事面板** | 环形对阵图 | 四名选手在环上、环印、下一轮配对 |
| **图鉴 / 收藏** | 环藏目录 | 书脊、抽屉、索引环、空白页（未解锁） |
| **结算** | 记印台 | 环印变化、缎带、饮料、观众席 |

### 6.3 字体与颜色

- 深色背景用羊皮纸色文字；浅色背景用墨色文字；不要纯白纯黑。
- 关键词用元素色，但保证对比度；毒系的酸黄不要用在白底上。
- 数字用等宽或衬线数字；费用、伤害、环刻要一眼可读。
- 按钮像黄铜铭牌或蜡封，不要圆角塑料按钮。

### 6.4 UI 中的阿环

- 阿环可以作为 UI 的“光标”与“提示员”：报分、指向、展开面板。
- 不要让阿环挡住信息；它停在边缘或角落。
- 阿环的分裂环可以组成加载动画、配对转盘、进度环。
- 阿环的铃声可以对应 UI 音效；不要用电子提示音。

## 7. 特效（VFX）

### 7.1 法弹

| 系 | 弹体 | 尾迹 | 命中 | 声音 |
|---|---|---|---|---|
| **火** | 暗红核心 + 橙光边缘 | 黑烟 + 火星，向上飘 | 黄铜色火花 + 热浪环 | 爆裂、低鸣 |
| **水** | 青白水核 + 玻璃高光 | 水带 + 细小水珠 | 涟漪 + 玻璃珠飞散 | 拍岸、清脆 |
| **土** | 灰褐石核 + 晶面 | 碎石 + 尘土 | 石片堆叠 + 闷响 | 闷响、碎裂 |
| **风** | 白色风核 + 青边 | 细弧 + 羽毛 | 干净切线 + 延迟风压 | 裂帛、呼啸 |
| **毒** | 橄榄绿核 + 梅紫边 | 孢子 + 气泡 | 菌丝绽放 + 溶解 | 嘶嘶、气泡 |

注意：

- 不要画写实火焰、写实水花、写实毒气；用风格化的形状与材质。
- 法弹不是子弹；不要画弹壳、枪口、硝烟。
- 命中特效不要遮住角色；持续时间短，留出读牌时间。

### 7.2 防御与治疗

- **护盾**：半透明六边形/晶洞壳，边缘有黄铜刻度；命中时出现裂纹与光，破碎时化为光尘。
- **治疗**：暖光从下往上、细雨/茶汽、珍珠色光点；不要白十字、不要天使。
- **毒层**：目标脚下/身边出现菌丝与孢子环；层数越多，菌丝越密；不要绿色毒气云。
- **风痕**：细小的白色刻痕，像玻璃上的划痕；引爆时刻痕同时亮起、碎裂。
- **余烬**：橙红小点在法印周围环绕；消耗时向法弹飞去。
- **潮汐**：水光环在法印与法弹之间往返；记录时水位上升。
- **逆息**：环场边缘向内收缩，黄铜刻度逆转，双方战息被抽走；不要红色警报。

### 7.3 环相与残响

- **环相**：从法印后方缓缓升起，半透明、元素色、带环纹；体型 2–3 层楼高；不要说话、不要做表情。
- **残响**：蓝白 + 黄铜线框的人形，边缘有扫描线/环纹；不是幽灵，不要透明飘忽的鬼魂。
- **开环**：万环之心的环纹逐层亮起，黄铜刻度旋转，五道地脉光从外圈汇入中心；不要爆炸式白光。
- **闭环**：环纹从外向内收拢，胜者法印落入环眼，光柱升起；观众席灯笼同时亮起。

## 8. 角色与关键视觉

### 8.1 群像

**开环**：

- 构图：万环之心中央，柯温站在环眼前，阿环停在肩边；五席围成半环，玩家在缺口处（背对或侧对镜头）。
- 动作：柯温抬手点灯；伊格娜抱臂笑；玛琳端茶；奥仑检查石缝；塞拉靠着灯笼杆；薇尔提着篮子。
- 光：黄昏 + 环光从下往上；背景是环庭台地与灯笼。
- 情绪：不是“英雄集结”，是“老同学聚会终于开始了”。

**黄昏决斗**：

- 构图：两座咏台左右，法弹在中央；观众在前景边缘，端着食物。
- 动作：一方刚打出法弹，另一方举盾；不要血腥、不要惨叫。
- 光：环场玻璃反射黄昏；法弹照亮双方脸部。
- 情绪：紧张但欢乐；像一场重要的友谊赛。

**法印生长**：

- 构图：一只手把一页咒式按进环眼；法印的同心环纹逐层亮起；五系颜色在边缘试探。
- 用途：Steam 竖版 capsule、加载图、教程封面。
- 情绪：安静、仪式感、邀请玩家进入。

### 8.2 角色图规格

- 全身：3/4 视角，站姿，中性羊皮纸背景；脚底留阴影；比例 7–7.5 头身。
- 半身：胸口以上，稍微侧身；背景虚化；用于对话与卡牌风味。
- 表情：至少 3 个——放松、认真、笑；不要只有战斗脸。
- 道具：每人至少一个可识别道具，且在不同图中保持一致。
- 色板：严格使用五系色板；不要给角色加“个人幸运色”破坏体系。

### 8.3 角色剪影检查

把五个角色涂成纯黑剪影，应该能一眼分辨：

- 伊格娜：宽肩 + 锤子 + 短披风。
- 玛琳：直身 + 长杖 + 长辫。
- 奥仑：方肩 + 背包 + 折凳。
- 塞拉：轻身 + 长围巾 + 邮包。
- 薇尔：宽帽 + 篮子 + 层叠披肩。
- 柯温：高瘦 + 灯杖 + 长外套。
- 阿环：一枚环，不用剪影也能认。


### 10.8 工作流

1. **先做 style sheet**：同一提示词生成 6–8 张不同主体，选 3 张作为参考。
2. **锁定参考**：后续图使用同一 style reference / image prompt / seed（工具支持时）。
3. **先黑白剪影**：角色与卡牌先确认剪影，再上色。
4. **再上色**：严格使用五系色板；不要每张图重新发明颜色。
5. **最后构图**：卡牌留安全区；场景留 UI 空间；角色留文字空间。
6. **不要生成文字**：所有名称、效果、数字在引擎中合成。
7. **人工修线**：AI 图的手、环纹、文字区域必须人工检查与修正。
8. **并排检查**：五张图放一起，如果有一张像另一个游戏，重做。

## 11. 一致性与审查清单

### 11.1 每张图都要过

- [ ] 主色是否来自对应元素色板？
- [ ] 线宽是否与同批图一致？
- [ ] 主光是否来自左上（或明确的场景光源）？
- [ ] 剪影是否一眼可读？
- [ ] 是否有现代/科幻/枪炮元素？
- [ ] 是否有文字、签名、水印、logo？
- [ ] 卡牌插画顶部 15%、底部 25% 是否留空？
- [ ] 角色比例是否 7–7.5 头身？
- [ ] 毒系是否避免了荧光绿、骷髅、毒气罐？
- [ ] 火系是否避免了写实火焰与爆炸？
- [ ] 水系是否避免了纯蓝与塑料感？
- [ ] 土系是否避免了沙漠黄与笨重感？
- [ ] 风系是否避免了纯白与轻浮感？
- [ ] 是否有“手作感”，而不是“素材拼贴感”？

### 11.2 五张并排检查

- 五个角色放在一起，是否像同一个世界的人？
- 五张卡牌放在一起，是否像同一套牌？
- 五个场景放在一起，是否像同一块大陆？
- 如果有一张“跳出来”，不是重画，就是重调色。

### 11.3 常见失败

| 问题 | 表现 | 修正 |
|---|---|---|
| 元素靠颜色硬区分 | 火=红、水=蓝、毒=绿，形状一样 | 用形状语言与材质区分 |
| 卡框太花 | 边框比插画亮 | 降低边框饱和度与细节 |
| 角色像不同游戏 | 线宽、比例、光向不一致 | 先做 style sheet，统一参考 |
| 毒系太恐怖 | 骷髅、绿烟、瘟疫医生 | 改成菌菇、果酱、药园、梅紫橄榄 |
| 火系太写实 | 照片级火焰、爆炸 | 改成余烬、黑烟、黄铜火花 |
| UI 太科幻 | 霓虹、全息、玻璃 HUD | 改成羊皮纸、黄铜、星盘、蜡封 |
| 文字糊在画里 | AI 生成乱码字 | 不在图里生成文字，引擎合成 |
