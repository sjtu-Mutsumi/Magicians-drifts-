# 土系命名定稿 · v1.2

30张卡牌，26处改名，4张保留。原临时壁垒最终定名为沙堡。

仅修改展示命名，保留稳定运行标识，不更改费用、攻防、首次附魔层数、效果、库存或AI。五系定稿显示名已通过 V12CardPresentation 接入 Data/Presentation/card-display.json，不直接修改规则内核的卡名键。新增或修改展示名后，先运行 `python tools/build_v12_presentation.py`，由五系 *-name-map.json 重新生成显示资料。小字保留 display_in_match=false，不在局内显示。

不周山、万钧碎盾、碎盾术、碎岩印记保留原名。壁垒与碎盾等机制名称不随卡名改动。
