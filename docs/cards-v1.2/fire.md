# 火系卡牌 · v1.2冻结版

数值与效果以本冻结版为准。通用术语、叠加方式与读取时点见[现行规则](README.md)及[结算规范](snapshot-contract.md)。

固定攻击、防御每次成功打出均获得；“首次元素层”按每张实例每场仅一次。能力牌成功打出后移出本场。

本页使用运行卡名。火系命名资料与风味文案另存[命名资料](fire-names.md)，不构成额外卡牌或另一套效果。
