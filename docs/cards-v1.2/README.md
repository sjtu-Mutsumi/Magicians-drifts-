## 统一术语

固定攻击、防御每次成功打出均获得，均仅在本场战斗内有效。首次附魔层按每张实例每场一次；回收或洗牌不重置。专精及非叠层传奇是能力牌，成功打出后移出本场。初始8张为攻击强化×2、防御强化×2、护盾、检索附魔、短促、重洗；这6种牌不进入市场。

“抽牌”加入手牌并计抽取记录；“回收”从弃牌堆加入手牌，不算抽牌。“置顶”不即时入手。“洗混”合并摸牌堆与弃牌堆后洗牌，不自动抽牌，正在结算的本牌不参与。

## 数值叠加

同类临时正向数值加算，重复打出也加算。例如猛火弹20%＋引火5%＝下一发主弹普通增伤25%；烈焰冲刺减10＋短促减5＝临时减间隔15。同一增幅区内百分比用百分点相加。临时攻击与主弹专属临时攻击在主弹上相加，副弹不继承主弹专属项。

临时防御穿透、护盾穿透分别相加，再与常驻来源相加，最终各封顶100%。发射前削盾百分比相加并封顶100%，按发射前同一总盾量一次计算；实际削盾成功时，裂空穿云的永久减间隔按叠加次数结算。所有直接加伤（潮汐、血潮支付、盾衰减转伤、高温炉心等）相加，各项仍按自身时点和实际资源取值。

常驻、元素、永久成长保持原公式。不同乘区仍按公式乘算：主弹原值＝[(有效攻击＋主弹专属临时攻击)×血统攻击倍率＋直接加伤合计]×(1＋普通临时增伤合计)。火附魔最终增伤、余烬乘区及减伤随后结算。最终间隔最低1，费用最低0。

下一张同系牌减费、下一段盾伤回复比例、潮汐增幅、耗潮转盾比例及握盾增幅也加算。奖励次数、副弹段数依原词条增加。明确“每场一次”、触发条件、能力激活与布尔保护资格不因本规则增加次数。

临时减间隔在下一次主弹发射完成后，用于安排再下一发；不改变已经排定的发射时间。下一段减伤与盾伤回复在下一段普通飞弹结算时消费，实际吸收量为0也会消费。负面效果按各自词条：蚀刻取最大，恐惧逐次乘0.8；减疗总上限60%。治疗受已损失生命、减疗等限制；生命支付向上取整且保留至少1生命。水附魔只按飞弹实际生命伤害×水层×3%回复，选择水专精后6%，不计盾伤；回复量先应用减疗，再向上取整并受已损失生命上限限制。

普通获盾使旧普通护盾保留75%（向上取整），临时护盾按批次处理。攻击间隔先算固定项，再乘百分比修正，最后向下取整并至少1。每100行动值进入抽牌阶段；1200行动值起，每阶段出牌后按ceil(当前生命×(0.05＋绝对行动值/10000))疲劳扣血。

完整时序见[结算规范](snapshot-contract.md)，逐卡绑定见[snapshot-audit.md](snapshot-audit.md)。[固定攻防预算](panel-budgets.md)与历史[修改记录](change-history.md)分开保存，历史数值不覆盖当前卡表。

## 基础战斗规则

每场初始生命1000、攻击100、防御40、基础间隔50；每100行动值的抽牌阶段基础抽5张、获得3费，未用手牌在阶段结束随机回插摸牌堆。首次主弹在100行动值发射。所有本场成长在下一场战斗重新开始。

|附魔|每层效果|选择对应专精后|
|---|---|---|
|火|自身伤害最终倍率增加1.5%，适用于普通飞弹、真伤、毒伤及碎盾伤害|每层3%|
|水|普通主弹及普通副弹实际生命伤害的3%转为回复，不计盾伤|每层6%|
|土|每次主弹发射前，获得ceil((有效攻击＋有效防御)×土层×2%)普通护盾，再计额外固定盾与获盾增幅|每层4%|
|风|固定攻击间隔减少0.5|每层减少1|
|毒|主弹实际扣除生命后施加1毒层；每100行动值触发攻击力×自身毒附魔层×目标毒层×2%的基础毒伤，扣目标50%防御并穿透护盾|基础毒伤系数4%|

以上基础专精收益按构筑时选择的专精启用；专精能力卡的余烬、潮汐、壁垒、疾风与瘟疫机制仍需正式打出激活。普通飞弹包括主弹与普通加成副弹，天岚真伤副弹独立分类。真伤穿盾且不扣防御，仍应用自身火附魔最终倍率；普通飞弹的专属增益不自动用于真伤。

毒层自然衰减间隔为ceil(max(1,100÷当前毒层数的整数商)×(1＋20%×缓释毒素次数))，最低1行动值；每次变化重新计算，缓释毒素生效时保留已经历进度，蚀骨保留最后1毒层。卡牌的直接施毒不要求普通主弹命中。

正式冻结快照位于releases/v1.2/cards.json，核验命令为python tools/verify_v12.py。冻结范围、1000局基线与确认记录见[冻结确认](freeze-confirmation.md)。历史研究报告保留原始数值，不作为现行规则。
