# v1.2 固定攻防：统一功能分档

2026-10-29。183张冻结卡牌的固定攻防预算，按品质与功能档统一校验。

`V = (攻击 + 1.5×防御) / ((费用 + 1)/2)`。数值牌使用原品质区间，强运转使用其70%，弱运转使用其90%。同一品质、同一功能档位对所有元素相同；弱势元素不能获得另外一套区间，可以在本档区间内调整，或通过机制处理。

|品质|数值牌100%|强运转70%|弱运转90%|
|---|---:|---:|---:|
|普通|5—6|3.5—4.2|4.5—5.4|
|稀有|7.5—9|5.25—6.3|6.75—8.1|
|史诗|9.5—11|6.65—7.7|8.55—9.9|
|传奇|11.5—13.5|8.05—9.45|10.35—12.15|
|专精|14—16|9.8—11.2|12.6—14.4|

攻防为整数，V必须落在对应区间内；表中派生端点不做二次舍入。五张指定3费永久叠加牌使用下述独立机制预算。

- **强运转**：即时抽牌、定向即时抽取、即时加费；本阶段定向减费也属于强运转。条件满足才兑现、首次限定或混合分支不改变分类。
- **弱运转**：检索置顶、跨回合抽牌或加费；纯洗牌、直接弃置、弃牌回收也属于弱运转。回收不视为抽牌。
- 同时具有强弱效果时按强运转。传奇能力牌不另设豁免，按效果所在档位校准。
- 只涉及治疗、护盾、余烬、潮汐、施毒或攻击间隔的牌，不因这些资源或时点文字自动归运转档。

例如枯潮、循毒、开岩、战术、风痕回廊按强档；导火索、连环潮、岩拳按强档；不灭烈焰、重洗、盾之共鸣、灰烬循环、禁忌知识按弱档。狂战和换页有即时抽牌，按强档。

当前32强、32弱、119数值，共183张。完整权威分类及基准区间见[panel-budgets.json](../../tools/sim_v12/rules/panel-budgets.json)。`tools/audit_v12_cards.py`按“品质＋功能”核对区间；同档最大V/最小V≤1.2，除以70%/90%还原到数值牌基准后的同品质最大/最小也≤1.2。AI读取当前攻防与功能标签；模拟器固定面板按现行卡表执行。

## 指定3费永久叠加牌的机制预算（2026-10-29）

熔盾烈焰、奔流、层岩结构、风暴、缓释毒素按稀有数值档7.5—9的80%，即V6—7.2校验，现统一取V7.0。史诗稀有度、3费与卡效不变；深渊使用史诗数值档，当前V10.75。该机制组优先于原史诗数值预算，不是按epic乘80%，也不按已折算的稀有运转档再次乘80%。

角色数量仍32强、32弱、119非运转数值；119中5张采用上述机制预算。审计比例按预算组计算，除以本组倍率后归还至参考稀有度（这5张为rare），其余仍按原功能档。导出panel_budget_group与panel_reference_rarity供AI库存和报告识别；不改变原功能角色标签。
