# v1.2 规划与同位次结算规范

183张卡牌，独立Python strict内核执行。卡面数值见六元素当前卡表；同类临时数值按README加算叠加。

## 三种状态

|状态|用途|
|---|---|
|轮初事实S0|毒伤、衰减、到期及下阶段资源兑现后的真实状态|
|个人规划P|自己的手牌、费用、资源预算及已规划前缀，不读取对手未揭示动作|
|位次事实Ck|正式第k位开始的真实状态，供战斗数值、真实资源与伤害读取|

阶段指每100行动值的抽牌阶段，赛事轮次另计。即时抽牌不新建阶段，牌序执行不推进全局行动值，不穿插自然毒伤、衰减或常规飞弹。

## 规划与正式提交

P按自己的前缀递进，可以预计自身确定的支付、获盾、治疗、施毒与资源联动以安排运转，但不造成真实伤害，不预支未知命中、敌伤破盾、反伤、斩杀或复活反馈。

抽牌、选择、洗牌随机动作、实例、弃置、回收、置顶、费用和运转混合分支在P锁定。正式只提交已到位前缀一次，不重新抽样、改选或改分支。真实资源不足时最多消耗实有量，不补造资源；不足不撤回已锁定的手牌或返费承诺。尚未到位的尾段不提交任何效果。

纯战斗数值按Ck读取；能力到位才激活。本牌固定面板与首次层在本位效果后提交，不影响本牌的前置读取。卡面明确的先后顺序仍有效，例如疾风连斩先永久减间隔1，再判本牌阈值。

## 同位次、死亡与保护

双方同位次读取位前快照，提交本位完整事务。对方本位新增护盾、治疗及保护不能挽救本位致死伤害；前位已到位保护可用。生命支付和卡内明确耗盾按自身真实顺序处理。同位净化只清位前已有负面，本位新增毒等保留；真实毒层增加/减少去重后才触发成长。

每位结束处理护命、死亡和已激活复活。保留1生命的护命不算死亡，可继续牌序；触及死亡边界即截断该方剩余牌序，复活也不恢复尾段。未复活的真正死亡结束战斗；复活后对手仍按原索引执行剩余序列。时光倒流每场最多一次、记录后200行动值内生效。

清除毒层会解除由毒专精动态派生的攻防减少，不额外算另一种净化效果；永久减防不属于可净化临时负面。能力、附魔层和永久成长均只限本场。

## 真实事件

治疗只按实际恢复计潮汐，不记录溢出治疗。普通水附魔吸血只认飞弹实际生命伤害，不认盾伤。余烬、潮汐、生命和护盾消耗只记实际支付，不将P预计量复制为正式收益。直接加伤的各来源分别按自身时点计值，再加总。

主弹发射前先产生土附魔护盾，因此该盾可抵挡同一行动值的常规飞弹；这一时点与同位次卡牌事务不同。普通副弹依队列逐段命中；天岚真伤副弹永远位于该发射组全部普通副弹之后，风痕引爆在其后读取前序真实命中叠加的层数。发射结束清除已消费的下一发状态，保留永久成长。

自然毒伤、自然衰减、到期及延迟资源在正式时间线触发，不由规划额外推进。抽牌阶段开始前按注毒、毒伤、自然衰减、到期和抽牌/待发奖励处理；阶段出牌后检查疲劳。当前疲劳从1200行动值开始。

逐卡角色与特殊读取见[snapshot-audit.md](snapshot-audit.md)及机器数据snapshot-contract.json。静态绑定检查不等于穷举所有交互，机制执行由回归及逐局核验补充。
